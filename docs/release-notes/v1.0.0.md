First release of **WebDM (Web Download Manager)**, a Windows x64 download manager based on AB Download Manager 1.10.4.

## Highlights

- **Fast downloads:** multiple connections per file, pause/resume, queues with a scheduler, speed limiter, categories
- **Video streams:** HLS with a quality choice, AES-128 encrypted streams, fMP4 and live recordings, saved as one file
- **Rebuilt streams:** videos a page plays from numbered segments without a playlist are put back together
- **Separate video + audio** (DASH-style players such as Facebook): downloaded in parallel and merged
- **Video sites through yt-dlp:** YouTube, Facebook, Instagram, X, TikTok, Vimeo and more, with a quality list
- **ffmpeg and yt-dlp included**; Settings → Tools keeps them up to date
- **Browser extension** for Chrome, Edge, Brave and Opera: download capture, right-click menu, floating
  *Download with WebDM* button on players (also inside iframes), per-site switches
- **Drag and drop** onto the main window or a floating drop target
- Runs next to AB Download Manager (own data folder, port 15515, native messaging host `com.webdm.app`)

## Install

1. **App:** run `WebDM_1.0.0_windows_x64.exe` (installs for your user, no admin rights), or unzip
   `WebDM_1.0.0_windows_x64.zip` for the portable version. Windows SmartScreen may warn because the build isn't
   code-signed: **More info → Run anyway**.
2. **Extension:** unzip `WebDM_Extension_1.0.0_chromium.zip` to a folder you keep, open `chrome://extensions`
   (or `edge://extensions`), turn on **Developer mode**, click **Load unpacked** and pick the folder.

Full instructions: [README → Installation](https://github.com/Mashrafi-Zaman/webdm#installation) and
[Browser extension](https://github.com/Mashrafi-Zaman/webdm#browser-extension).

## Known limitations

- Windows 10/11 x64 only; no Firefox extension
- The installer isn't code-signed yet, so SmartScreen warns on first run
- The extension isn't in the Chrome Web Store: it's loaded unpacked and updated by unzipping the new version over the
  old folder
- DRM-protected streams (Widevine, PlayReady, FairPlay) are not supported
- Video sites change often; if one stops working, update yt-dlp in Settings → Tools
- New WebDM texts (Tools page, video options) are in English only; the other 27 languages come from AB Download
  Manager
