Bug-fix release of **WebDM (Web Download Manager)**.

## Fixed

- **Browser extension:** tiny audio/video files are no longer offered as downloads. Some sites preload short interface
  sounds (for example voice-search sounds named "open", "success", "failure" and "no_input", about 6 KB each); on
  pages without a real video these showed up in the *Download with WebDM* list. Whole files under 64 KB are now never
  listed. Real videos on the same page are still found.

## Update

- **App:** run `WebDM_1.0.1_windows_x64.exe` over your current installation (your downloads and settings are kept),
  or unzip `WebDM_1.0.1_windows_x64.zip` for the portable version.
- **Extension:** unzip `WebDM_Extension_1.0.1_chromium.zip` over your existing extension folder, then click the
  reload button of WebDM Integration on `chrome://extensions` (or `edge://extensions`).

First time? See [README → Installation](https://github.com/Mashrafi-Zaman/webdm#installation).
